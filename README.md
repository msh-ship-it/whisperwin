# WhisperWin

Локальный voice-to-text для windows на `mlx-whisper`.

## Что это

`WhisperWin` записывает голос с микрофона, транскрибирует локально и вставляет текст в активное приложение.

Просто скачай и запусти exe. Введи ключ Groq - если есть. Для распознавания и ввода текста - установи курсор в поле ввода, зажми правый ctrl - и говори
