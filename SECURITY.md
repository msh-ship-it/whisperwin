# Security & Privacy

## 1. Data flow

- Звук с микрофона пишется локально (`sounddevice`) и не сохраняется на диск
  как отдельный файл — только в оперативной памяти на время записи.
- Распознавание — либо облачное (Groq API), либо полностью локальное
  (`faster-whisper`, без сети). Выбор движка — `WHISPERMAC_ENGINE=groq|local`.
- Транскрипт вставляется в активное приложение через системный буфер обмена
  + синтетический `Ctrl+V`.
- Опционально создаются локальные файлы:
  - `~/whisper_log.txt` — история распознанного текста
  - `~/whisper_perf.log` — метрики скорости
  - `~/whisper_runtime.log` — диагностика фокуса/вставки

## 2. Network behavior

- Ключ Groq API **не хардкодится** и в репозиторий/установщик не попадает —
  каждый пользователь вводит свой в диалоге настроек (правый клик по виджету
  или иконка в трее), ключ хранится локально в
  `%APPDATA%\WhisperWin\config.json`.
- Аудио отправляется на серверы Groq (`api.groq.com`) только когда движок —
  `groq` и ключ задан. При `WHISPERMAC_ENGINE=local` сеть не используется
  вообще (после того как модель `faster-whisper` закэширована).
- На первом локальном запуске модель `faster-whisper` может быть скачана из
  Hugging Face.

## 3. Recommended secure mode

Для приватных сессий — полностью локально, без сети:

```powershell
$env:WHISPERMAC_ENGINE = "local"
$env:WHISPERMAC_SAVE_TRANSCRIPTS = "0"
$env:WHISPERMAC_SAVE_PERF_LOG = "0"
```

## 4. Known limitations (Windows-specific)

- Синтетический ввод (`Ctrl+V`) не может попасть в окно, запущенное с более
  высокими правами (UAC/administrator), если сам WhisperWin запущен без
  повышения — это ограничение Windows (UIPI), не баг.
- Нет аналога macOS Accessibility API для прямой вставки текста в обход
  буфера обмена — единственный путь: буфер обмена → фокус на целевое окно →
  `Ctrl+V`.

Подробнее: [`docs/WINDOWS_RU.md`](docs/WINDOWS_RU.md).

## 5. Threat model (short)

- Защищает от утечки через хардкод API-ключей в коде/установщике (их нет —
  ключ вводит сам пользователь и он живёт только локально).
- В режиме `local` защищает от утечки аудио на сторонние серверы вообще.
- Не защищает, если устройство уже скомпрометировано локально.
- Не защищает от лог-утечек, если включено сохранение транскрипта
  (`WHISPERMAC_SAVE_TRANSCRIPTS=1`, по умолчанию).
